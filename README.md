# 鹈鹕骑单车 · Pelican on a Bike

一只戴头盔、围红围巾的白鹈鹕，骑着复古单车沿海岸线追鱼。实时 3D（three.js），场景、模型、贴图和音效全部程序化生成，没有任何外部素材。

沿途还有一条「哲学之路」：用车道回答门架上的思想岔路，遇见芝诺之鱼、布里丹之驴、忒修斯之船与庄周梦蝶，最后得到你的哲学画像。

**在线试玩：** https://supera7.github.io/pelican-bike/

## 操作

| 按键 | 作用 |
|---|---|
| W / S | 加速 / 刹车 |
| A / D | 变道（也是在思想岔路上作答） |
| 空格 | 跳跃 |
| T | 放手特技 |
| B / H | 按铃 / 鹈鹕大叫 |
| C | 切换镜头 |
| Z | 庄周梦蝶 |
| J | 哲学画像与思想图鉴 |
| N | 时间快进 3 小时 |

## 本地运行

```bash
python3 -m http.server 8765
```

然后打开 http://localhost:8765 。

中国古典引文为原文；西方思想家的话为本游戏自写的大意转述。
